# Multi-Institute Phase 3A — Platform Provisioning Primitives\n\nProtected platform-control operations are now available as database functions.\n\n## Create institute\n\ncreate_institute(name, slug, timezone, locale):\n\n1. requires an active platform membership;\n2. creates the institute as trial;\n3. creates its settings row;\n4. seeds standard tenant roles and permissions;\n5. writes a platform audit event.\n\n## Register a domain\n\nregister_institute_domain(institute_id, hostname, domain_type):\n\n- accepts custom or default_subdomain;\n- creates a pending domain row;\n- generates a verification token;\n- records an audit event.\n\nActual DNS verification and TLS certificate provisioning remain infrastructure work.\n\n## Safety\n\nBoth functions are SECURITY DEFINER, deny public/anonymous execute, and require the authenticated caller to be a platform member.
